About SkyCast

Developed by: R. Navyashree

Project: SkyCast – Full-Stack Weather Application

SkyCast is a weather application that provides current weather conditions, five-day forecasts, historical weather information, and location-based weather search. Users can save locations, manage saved weather records, and export data in CSV and JSON formats.
