When a user uses the application, it should work like this:
1. Search for a city: The user enters a city, town, landmark or ZIP/postal code to find its weather.
2. Detect current location: The user allows browser GPS permission to automatically detect their current location.
3. View current weather: Display current temperature, weather conditions, humidity, wind speed and other relevant weather details.
4. View 5-day forecast: Display the weather forecast for the next five days.
5. Retrieve historical weather: The user selects a date range to retrieve historical weather information for a location.
6. Save weather searches: Store the searched location, selected dates and retrieved weather information in MongoDB.
7. Manage saved searches: Allow users to view, edit, refresh and delete their previously saved searches.
8. Export weather reports: Allow users to download weather reports in CSV and JSON formats.
9. View location on an interactive map: Display the searched location on an interactive map with a location marker.
10. Handle errors: Display appropriate messages for invalid locations, unavailable GPS permissions, invalid date ranges and API failures.
11. Use the application on different devices: Provide a responsive interface for desktop, tablet and mobile.
